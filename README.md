# Тони и Эйрин

Веб-приложение для телефона (PWA): уход за котом Тони и собакой Эйрин.
Отметки кормления с суточной нормой, прогулки, игры, вода и лоток, дела с повтором
и тамагочи: шкалы сытости, радости и ухода растут от действий и убывают со временем.
Один пользователь, данные хранятся только на телефоне (`localStorage`).

Всё приложение в одном файле `index.html`. `sw.js` — офлайн-кэш: при изменении файлов поднимать `VERSION`.
Выкладка: GitHub Pages, ветка `main`. Обновление = коммит + `git push`.
